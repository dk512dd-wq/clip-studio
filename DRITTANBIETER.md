|---|---|---|
| D-DIN, D-DIN Condensed (Datto) | SIL Open Font License 1.1 | `studio/fonts/` (Lizenztext in `D-DIN-OFL.txt`) |
| IBM Plex Mono | SIL Open Font License 1.1 | über Google Fonts |
| Bebas Neue, Montserrat | SIL Open Font License 1.1 | `engine/fonts/`, Vorschau über Google Fonts |
| YuNet Gesichtserkennung (OpenCV Zoo) | MIT | `engine/models/` |
| yt-dlp | Unlicense | wird bei der Installation geladen |
| Whisper large-v3-turbo (OpenAI), mlx-whisper, faster-whisper | MIT | wird bei der Installation geladen |
| OpenCV, NumPy, Pillow | Apache 2.0, BSD, HPND | wird bei der Installation geladen |
| ffmpeg über imageio-ffmpeg | LGPL/GPL | wird bei der Installation geladen |
| Open iPhone Use (semsturgut/open-iphone-use) | siehe dort | wird nur für das iPhone-Modul aus dem Original-Projekt geladen |
